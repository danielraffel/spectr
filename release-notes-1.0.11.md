# Spectr 1.0.11

Fixes a crash when reopening a session that contains a saved Auto Gain estimate.
The restored estimate now remains valid while its spectrum rows are copied.

Linux builds incorporate the framework fixes for dropdown keyboard navigation,
pointer modifiers, popup focus and hover cursors.

Release qualification is in progress. Download links and platform entries will
be added after the exact installers and archives pass their installed-product
checks. Existing 1.0.10 downloads and the Apple silicon updater feed remain
available during qualification.
