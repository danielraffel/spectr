# Spectr on Vellum step 0 receipt

Built on the fast-forwarded `lane/b1c-spectr-capture` head with the read-only SDK prefixes supplied for this lane. The CLAP was configured with `SPECTR_VELLUM_EDITOR_PACKAGE=ON`.

The package root now creates Vellum's model-backed `ScriptedUiSession` over the
per-editor `ParamPortModel`. The allowlist resolver covers the plain controls,
both LFO lanes, and all LFO route enable/depth controls. The legacy native
editor remains selected when the option is OFF.

## Offscreen editor

The probe was run without the GPU-disabling environment variable. The sandbox
reported `IOSurfaceSharedEventAddEventListener failed: 10000003` and exited
before a frame receipt. Treat the Vellum backend as Null here. Pixel-diff and
editor repaint proof must be rerun by the lead outside the sandbox with a real
GPU.

## Offline audio

The SDK `pulp audio render` path produced dry, wet, automation, restore, and planted/unplanted renders. The planted `Output Trim` change is 0.1 dB and has a distinct WAV hash from the unplanted render.

## Not proven

- Visible editor response to the changed Mix value, because the offscreen frame diff was 0 pixels.
- Product UX in a DAW, on-screen windows, live audio, installation, and system plug-in discovery. Those were intentionally not exercised.

Note: the probe logs, WAVs and PNGs named above are generated by `tools/vellum-step0/run_step0.sh` and are not committed to this branch. The script now exits non-zero when the editor probe fails (the changed-control assertions currently fail, so the editor repaint is unproven). Override the SDK locations with `PULP_SDK` and `VELLUM_SDK`.
